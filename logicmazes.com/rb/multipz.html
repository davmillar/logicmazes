Andrew Fenwick’s Multi-Level Program

This implements six of Eric Friedman’s Multi-Level Rolling-Block Mazes. You may have to double-click on the diagram to get the program started. Click on Next to get to the maze described in the main section.

The goal in each of these mazes is to get the uppermost block to be exactly over the yellow square (or squares).

Only the blue blocks can move, and only the light blue block is currently active. Use the space bar to change which block is currently active.

You can use the arrow keys to move the blocks. Unfortunately these keys only point horizontally or vertically and the board is oriented on a diagonal. If you don’t like way the keys work, try pressing s. This will get the program to change which direction is associated with which key. If you still don’t like these keys, then activate the keypad on your keyboard and use 7, 9, 1, and 3.

Clicking on the view buttons will change your view of the board.
